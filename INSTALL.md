# Install Deadlock Item Assist

The window title is Deadlock Item Assist. The short name is DIA.

## Download

Download `Deadlock-Item-Assist-Setup-0.6.0.exe` from the release.

The file is not code-signed. Windows SmartScreen shows a warning. Choose More info, then Run anyway.

## Install

Run the installer. It can install for you or let you pick a folder. When it finishes, open Deadlock Item Assist from the Start menu.

## Deadlock

In Deadlock, open Video settings and set Display Mode to Borderless Windowed. The Deadlock window needs to be at least 1280 by 720. If the capture stays black, the app says to leave Fullscreen and use Borderless Windowed.

The app looks for a window titled exactly Deadlock.

## What you see

The app has three tabs:

- Draft advisor
- My Picks
- Street Brawl Tier List

## Hero

On Draft advisor, a hero read from the loading screen is marked auto. Press change and pick a hero in the list to pin that hero. Press auto-detect to let the loading screen choose again.

On My Picks, the hero list starts at Violet. While the app has read a hero, that hero's list is used. When it has not read a hero, the hero chosen on this tab is used.

## My Picks

Highlight My Picks starts on. A Main item gets a gold ring and a MY PICK tag. A Secondary item gets a dimmer ring and an ALT tag. The teal circle is still the app's own best pick. Both can show on the same card.

On the My Picks tab you can turn the highlights off, switch the saved list, add an item, remove an item, move an item between Main and Secondary, reset the list, or import a public build by its build id and version.

## Keys

Ctrl+Shift+O hides the overlay, or lets it show again. The overlay is on screen only while a Deadlock window is open and there is a draft, the ability panel, or the lobby mark to draw.

F8 reads the draft now. It is active only while a Deadlock window exists. If another program already uses F8, use Detect now (F8) in the tray menu.

Ctrl+Shift+D opens the debug panel in a development build or a release candidate. This shared build is a final build, so that key is not included.

The tray menu also has Toggle overlay, Detect now (F8), First-run check, Toggle test mode, and Quit.

## Uninstall

Open Windows Settings, Apps, Deadlock Item Assist, and choose Uninstall. You can also run the uninstaller from the install folder.

Uninstall removes the program. It leaves the settings folder `%APPDATA%\deadlock-street-brawl-helper` in place.
